AI-Native, Multi-Model Database Engine for Modern Android

KoreDB unifies Typed Documents, HNSW Vector Embeddings, and Property Graphs into a single zero-dependency, ultra-fast embedded LSM storage engine built in 100% Kotlin.

📄

Document Engine

O(1) LSM writes, CBOR zero-copy binary serialization, secondary string & numeric range indexing, and BM25 full-text search.

⚡

Vector Engine

Sub-millisecond Approximate Nearest Neighbor (ANN) search via HNSW, SQ8 quantization, off-heap memory-mapped indexing, and hybrid filtering.

🕸️

Graph Engine

Bidirectional property graph with cascading deletes, variable-length traversals, Dijkstra shortest path, A*, and PageRank algorithms.

🧬

Graph RAG Bridge

Combines graph traversal constraints with semantic vector similarity and BM25 text rank in a single fluent query.

📦 Installation

Add KoreDB to your module's build.gradle.kts:

repositories {
    mavenCentral()
}

dependencies {
    implementation("io.github.raipankaj:koredb:0.2.0")
    implementation("org.jetbrains.kotlinx:kotlinx-serialization-cbor:1.8.0")
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.10.1")
}

⚡ Quickstart

Initialize KoreDatabase in your application or repository layer:

// 1. Define your data class
@Serializable
data class Product(val id: String, val title: String, val category: String, val price: Double)

// 2. Open or create database
val db = KoreDatabase(File(context.filesDir, "app_data"))

// 3. Obtain a high-performance binary collection
val products = db.binaryCollection<Product>("products")
products.createIndex("category") { it.category }
products.createNumericIndex("price") { it.price }

// 4. Insert documents
products.insert("p1", Product("p1", "MacBook Pro M3", "electronics", 1999.0))
products.insert("p2", Product("p2", "AirPods Max", "electronics", 549.0))

// 5. Query by secondary index (5.7x faster than Room)
val electronics = products.find("category", "electronics")

// 6. Query by numeric range (6.1x faster than Room)
val budgetItems = products.findRange("price", 100.0, 600.0)

// 7. ACID MVCC Transaction (4.3x faster than Room)
db.transaction { tx ->
    val txCol = tx.binaryCollection<Product>("products")
    txCol.insert("p3", Product("p3", "Magic Mouse", "electronics", 99.0))
}
